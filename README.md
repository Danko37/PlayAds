1) Для выполнения тестового задания выбрал движок Unity 6000.4.9f1 потому, что у меня есть опыт комерческой разработки в нем.
2) Просто открыть проект в Unity 6000.4.9f1 и войти в плеймод. Что бы собрать проект в Unity нажмите в Tools->WebGl-> Build Single HTML. Это создаст index-single.html файл с игрой, который можно запустить в браузере компьютера или мобильного устройства.
3) 1. Аудио - главная экономия. Клипы импортируются в Vorbis (compressionFormat: 1), не сырым PCM WAV, а большинство ещё и Force To Mono (forceToMono: 1). Аудио - самый тяжёлый ассет в билде, так что это
  самый весомый выигрыш. Правда, quality: 1 (100%) и loadType: 0 (Decompress On Load) - есть куда ужимать дальше.
  2. Stripping движкового кода - stripEngineCode: 1 (вырезает неиспользуемые части рантайма).
  3. Удалены Addressables - из билда ушёл пустой каталог в StreamingAssets (мелочь, но чисто).
  4. WebGL Template = Minimal - без TemplateData/* (лого, css), только тело игры.
  5. IL2CPP + Wasm (webGLLinkerTarget: 1) - компактный wasm-код (это стандарт WebGL, не столько «оптимизация», сколько база).

  Что НЕ применено:

  - Managed Stripping Level — {} (дефолт, не High).
  - IL2CPP Code Generation — {} (дефолт «Faster runtime», не «Smaller build»).
  - Модули в manifest.json не чищены - висят visualscripting, timeline, cloth, terrain, vehicles, vr, xr, video, particlesystem и т.д., хотя игра их не использует.
  - Не использован плагин Unity Playworks.
  - Не использован Addressables.
  - Не использован gpu instancing.

  4) 1. Лучше бы настроил звуки и музыку. Подобрал бы более подходящие звукове файлы. Настроил бы уровни громкости.

Перед началом туториала, когда герой прибегает к стартовой точке, камера показывает его товарища (это та же модель героя, но с красной текстурой), который находится на верхнем ярусе локации. Он окружен гоблинами и просит о помощи. После этого начинается игра - наша цель добраться до него.В конце уровня герой сражается с главным гоблином (тем, который сейчас стоит в конце локации).
